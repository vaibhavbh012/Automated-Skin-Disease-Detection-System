# Contributing to Automated Skin Disease Detection System

Thank you for your interest in contributing to this project! We welcome contributions from developers, researchers, and healthcare tech enthusiasts.

Please follow these guidelines to make contributing smooth and effective:

## How to Contribute

### 1. Reporting Bugs & Requesting Features
*   Check the [Issues](https://github.com/vaibhavbh012/Automated-skin-disease-detection-system/issues) section first to see if it has already been reported.
*   Open a new issue describing the bug, steps to reproduce, and your environment (OS, browser, Python/Node versions).
*   For feature requests, describe the proposed feature and why it would be beneficial to the project.

### 2. Submitting Pull Requests (PRs)
*   Fork the repository and create your branch from `main`:
    ```bash
    git checkout -b feature/your-feature-name
    ```
*   Install development dependencies for both the frontend and backend.
*   Write clean, documented code and keep comments up-to-date.
*   Format your code and verify it builds without errors.
*   Commit your changes using clear and descriptive commit messages (following [Conventional Commits](https://www.conventionalcommits.org/)):
    ```bash
    git commit -m "feat: add support for real-time camera validation"
    ```
*   Push to your fork and submit a Pull Request to our `main` branch.

## Project Structure Overview

*   `/frontend`: React/Vite web application.
*   `/backend`: Node.js/Express API server.
*   `/model`: AI/ML model files, training scripts, and inspection helpers.

## Code Style & Standards

*   **JavaScript (React/Node)**: Follow ES6+ guidelines. Keep React components modular and style with Tailwind CSS.
*   **Python (AI/ML)**: Follow PEP 8 guidelines. Document model training hyperparameters and preprocessing steps.
